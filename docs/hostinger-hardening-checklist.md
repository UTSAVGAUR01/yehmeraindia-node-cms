# Hostinger hardening checklist

- Keep Node.js and dependencies patched.
- Rotate all exposed credentials.
- Enable Hostinger, GitHub and mailbox 2FA.
- Run only the expected Node entry point.
- Review runtime logs and resource graphs for unexplained CPU spikes.
- Rebuild from a trusted Git commit after a suspected compromise.
- Restrict database access and permissions.
- Keep secrets only in Hostinger environment variables.
